# LED Roulette Wheel Reflection

This project helped me practice controlling several LEDs with an array. I arranged six LEDs like a wheel and made the light move around them when I pressed the Spin button. The delay increased during the spin, which made the light look like it was slowing down before stopping on a random LED.

The most important part was making sure every LED had the correct GPIO connection and its own resistor. I also learned how a random number can control both the starting position and the number of steps in a game.

I liked this project because it turned basic LED sequencing into something interactive. In the future, I could add points, sound effects, or an OLED that displays the winning LED.
