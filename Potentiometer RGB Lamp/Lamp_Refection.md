# Reflection – Potentiometer RGB Lamp

This project strengthened my understanding of analog inputs, PWM, and RGB LED control using the ESP32. I learned how a potentiometer can provide variable analog values that are converted into digital readings and used to control LED brightness. Mapping the potentiometer values to PWM outputs helped me better understand how sensor data can be translated into real-time hardware responses.

One challenge was ensuring the RGB LED was wired correctly and understanding the difference between common cathode and common anode RGB LEDs. I also learned that the ESP32 uses PWM channels instead of the traditional `analogWrite()` approach found on many Arduino boards, which improved my understanding of ESP32-specific programming.

Completing this project increased my confidence in building interactive embedded systems. It introduced concepts that are useful for future projects involving sensors, lighting control, automation, robotics, and Internet of Things (IoT) applications. This project serves as another milestone in developing practical hardware and software engineering skills.
