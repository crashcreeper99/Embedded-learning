# Reflection – LED Binary Counter

For this project, I built an LED binary counter with an ESP32, four LEDs, and a button. Every time I pressed the button, the counter increased by one and the LEDs showed that number in binary. The counter went from 0 to 15 before starting over.

This project helped me understand binary in a physical way instead of only looking at numbers on a screen. Each LED represented a different value: 1, 2, 4, or 8. I learned how those values combine to represent decimal numbers.

I also practiced using arrays, loops, `bitRead()`, and button-state detection. I had to make sure one press only increased the counter once. Seeing the LEDs change while the decimal value appeared in the Serial Monitor made it easier to check that the program was working correctly.

Overall, the project worked successfully and gave me a better understanding of how computers represent numbers using bits. This connects directly to digital electronics, embedded systems, and computer engineering.
