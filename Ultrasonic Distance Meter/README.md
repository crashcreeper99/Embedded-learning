# Ultrasonic Distance Meter (ESP32)

## Overview

This project uses an ESP32 and an HC-SR04 ultrasonic sensor to measure the distance between the sensor and nearby objects. The measured distance is displayed through the Serial Monitor in real time.

## Components

* ESP32 DevKit V1
* HC-SR04 Ultrasonic Sensor
* Breadboard
* Jumper Wires
* USB Cable

## Features

* Measures distance continuously
* Displays measurements in centimeters
* Fast real-time updates
* Uses precise timing to calculate distance

## Skills Learned

* Working with ultrasonic sensors
* Sending trigger pulses
* Reading echo signals
* Time-of-flight distance calculations
* Digital input/output programming
* Serial communication

## Applications

* Obstacle detection
* Robot navigation
* Parking systems
* Smart home automation
* Distance measurement devices
