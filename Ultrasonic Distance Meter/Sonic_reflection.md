This project introduced me to ultrasonic distance sensing and how sound waves can be used to measure distance. I learned how the ESP32 sends a trigger pulse, waits for the echo signal, and calculates the object's distance using the travel time of the sound wave. I also improved my understanding of digital timing and sensor interfacing. This project strengthened my confidence in using sensors that require precise timing and showed me how this technology is used in robotics, automation, and smart devices.
