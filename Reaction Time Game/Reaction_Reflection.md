# Reflection: ESP32 Reaction Time Game

Completing the ESP32 Reaction Time Game helped me understand how embedded systems interact with users in real time. This project combined concepts I learned from previous projects, including controlling LEDs, reading button inputs, and programming the ESP32.

The biggest concept I learned was how to use timing functions like `millis()` instead of simple delays. Using accurate timing allowed the ESP32 to measure how quickly a user reacted after the LED signal appeared.

One challenge was making sure the button input was detected correctly and preventing false readings. Troubleshooting the wiring and code helped me better understand pull-up resistors and digital signals.

This project improved my confidence with ESP32 programming because it required both hardware connections and logical programming. Compared to simpler LED projects, this was a step toward building more interactive devices.

In the future, I would improve this project by adding an OLED screen, sound effects, multiple rounds, and a scoring system. This would make it closer to a commercial reaction-time game.

Overall, this project strengthened my skills in embedded programming, timing control, and designing user-focused electronics projects.
