# Servo Motor Controlled by Potentiometer (ESP32)

## Overview

This project allows a potentiometer to directly control the position of a servo motor. As the potentiometer is rotated, the ESP32 reads the analog voltage and converts it into a servo angle between 0° and 180°.

## Components

* ESP32 DevKit V1
* SG90 Servo Motor
* Potentiometer (10kΩ)
* Breadboard
* Jumper Wires
* External 5V Power Supply (recommended)

## Features

* Real-time analog control
* Smooth servo movement
* Angle mapping from potentiometer position
* Responsive user input
