# Servo Sweep Demo (ESP32)

## Overview

This project demonstrates how to control a servo motor with an ESP32 by sweeping it smoothly between different angles. The servo repeatedly rotates from 0° to 180° and back again.

## Components

* ESP32 DevKit V1
* SG90 Servo Motor
* Breadboard
* Jumper Wires
* External 5V Power Supply (recommended)

## Features

* Automatic sweeping motion
* Smooth angle transitions
* PWM servo control
* Adjustable movement speed

## Skills Learned

* PWM signal generation
* Servo motor control
* Angle positioning
* Motion programming
* Power considerations for motors

* Robotic arms

* Mechanical automation
