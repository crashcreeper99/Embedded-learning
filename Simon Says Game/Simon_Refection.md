# Reflection

The Simon Says Memory Game was one of the most enjoyable projects I have completed because it combined LEDs, buttons, and a buzzer into a fully interactive game. I learned how to generate random sequences, compare user input to stored data, and increase the difficulty as the game progressed.

During the build, I discovered that I did not have a separate blue LED available, so I used the blue channel of an RGB LED instead. By wiring only the blue pin of the RGB LED through a 220Ω resistor to the ESP32, I was able to replace a standard blue LED without changing the overall game design. This reinforced the idea that understanding how components work allows for creative problem-solving when parts are limited.

This project also strengthened my understanding of loops, arrays, conditional statements, timing, GPIO control, and hardware debugging. Getting every button, LED, and the buzzer working together required careful wiring and testing, which improved both my programming and troubleshooting skills.

Overall, this project increased my confidence in designing interactive embedded systems and prepared me for more advanced ESP32 projects involving displays, sensors, communication modules, and larger software designs.
