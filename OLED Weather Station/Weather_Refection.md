# Project Reflection – ESP32 OLED Temperature & Humidity Monitor

This project helped me gain a better understanding of how multiple hardware components work together in an embedded system. I learned how the ESP32 communicates with an OLED display using the I2C protocol while simultaneously collecting temperature and humidity data from a DHT sensor.

One of the biggest challenges was making sure the wiring matched the code and confirming that the correct sensor type and libraries were being used. Troubleshooting these issues taught me the importance of checking both hardware connections and software configuration before assuming something was broken.

I also became more comfortable formatting information on the OLED display, including changing text sizes, positioning text, and refreshing the display with updated sensor readings. These skills will be useful for future projects that require user interfaces and real-time data visualization.

Overall, this project strengthened my knowledge of embedded programming, hardware integration, and debugging. It also gave me confidence to build more advanced IoT systems such as wireless weather stations, smart home monitors, data loggers, and cloud-connected sensor networks.
