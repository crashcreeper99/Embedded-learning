# Parking Assistant (ESP32)

## Overview

This project expands the ultrasonic distance sensor into a parking assistant. The ESP32 measures the distance to an object and provides visual or audible feedback to help guide safe parking.

## Components

* ESP32 DevKit V1
* HC-SR04 Ultrasonic Sensor
* Active Buzzer
* LEDs (optional)
* Breadboard
* Jumper Wires

## Features

* Continuous distance monitoring
* Audible warning when objects get closer
* Adjustable warning thresholds
* Real-time feedback

## Skills Learned

* Sensor integration
* Conditional programming
* Distance thresholds
* Buzzer control
* Embedded system logic

## Applications

* Vehicle parking assistance
* Robot collision avoidance
* Warehouse automation
* Smart garages
