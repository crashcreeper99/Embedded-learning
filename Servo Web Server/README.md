# ESP32 Servo Web Server

## Overview

This project creates a web-based interface that allows users to control a servo motor from any device connected to the same Wi-Fi network. The ESP32 hosts a web server that accepts commands and moves the servo to the selected angle.

## Components

* ESP32 DevKit V1
* SG90 Servo Motor
* Breadboard
* Jumper Wires
* Wi-Fi Network

## Features

* Built-in web server
* Wireless servo control
* Browser-based interface
* Real-time angle adjustment
* No mobile app required
