# Reflection – Morse Code Transmitter

For this project, I created a Morse code transmitter using an ESP32, an LED, and a push button. Pressing the button made the LED transmit SOS with three short flashes, three long flashes, and three short flashes.

This project helped me understand how timing can represent information. The same LED was able to communicate different symbols just by staying on for different amounts of time. A dot lasted 200 milliseconds, while a dash lasted three times longer.

I also practiced dividing a program into smaller functions. I made separate functions for dots, dashes, the letters S and O, and the complete SOS message. This made the code easier to understand and would make it easier to add more letters later.

The project worked successfully, and I could clearly recognize the SOS pattern. It showed me that even a simple output like an LED can be used for communication when the timing follows an agreed system.
