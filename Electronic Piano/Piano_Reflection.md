# Reflection

Building the Electronic Piano helped me gain more confidence working with the ESP32 and multiple input devices. I learned how push buttons can be used to trigger different actions and how PWM can generate musical notes through a passive buzzer. During the project, I had to troubleshoot compilation errors and understand the difference between active and passive buzzers, which taught me that selecting the correct hardware is just as important as writing the code.

This project improved my skills in wiring circuits, reading button inputs, debugging code, and organizing programs. It also reinforced concepts such as GPIO configuration, loops, arrays, and conditional statements. Completing this project has prepared me for more advanced projects involving displays, sensors, and user interfaces, and it has strengthened my embedded systems portfolio.
